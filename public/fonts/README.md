# Self-hosted fonts

`newsreader-latin.woff2` (Newsreader variable, weights 300–600) and
`sora-latin.woff2` / `sora-latin-ext.woff2` (Sora variable, weights 400–800)
are Latin subsets downloaded from Google Fonts and served from `/fonts/`.

Both families are licensed under the SIL Open Font License 1.1:

- Newsreader: see `OFL-Newsreader.txt`
- Sora: see `OFL-Sora.txt`
